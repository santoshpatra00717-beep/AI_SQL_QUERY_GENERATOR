# AI SQL Query Generator

An AI-powered web application that converts natural language into SQL queries using Google Gemini AI and Streamlit.

## Features

- Convert English text into SQL queries
- AI-generated explanation of the SQL query
- Expected output table preview
- Simple and interactive Streamlit interface
- Powered by Google Gemini API

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- SQL

## Installation

1. Clone the repository

```bash
git clone https://github.com/OmmPrakash07/AI-SQL-Query-Generator.git
```

2. Install the required packages

```bash
pip install -r requirements.txt
```

3. Add your Google Gemini API key in a `.env` file.

4. Run the application

```bash
streamlit run app.py
```
